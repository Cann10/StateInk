# Product

## StateInk とは

StateInk は、静的な状態遷移図を実際に操作できる設計へ変え、設計ミスと再現操作を示す Web アプリです。メインコピーは「描いた設計を、動かして確かめる。」、サブコピーは「紙の状態遷移図を、実行・検証できる設計図へ。」です。

## 制作背景

大学の授業で自動販売機の状態遷移図を書いた際、状態が増えるほど紙の上で正しさを追うことが難しくなった体験が出発点です。画像認識そのものではなく、図を試せることに価値を置きます。

## Target User

第一に状態遷移図を初めて学ぶ大学生・高校生・専門学生、第二に簡単な状態設計を素早く検証したい開発者を対象にします。日本語の説明を先に、技術名称を補助的に示します。

## Product Vision

将来は「手書き図 → 画像認識 → IR → 実行 → 自動検証 → 問題の操作列 → 修正 → コード生成」を目指します。入力手段が変わっても、実行・解析の核は再利用します。

## Scope / Non-scope

Phase 1はブラウザ上のIR、Simulator、Analyzer、最短反例、Editorを提供します。Phase 2は白紙＋黒ペンの円・楕円・長方形と明確な矢印を対象に、OpenCVで編集可能な下書きを作ります。認識結果は必ず人が確認し、OCR完全対応は目標にしません。DB、認証、保存、共同編集、LLM、コード生成、高度なUMLは対象外です。
